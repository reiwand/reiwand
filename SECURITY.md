# Security

Report a security problem privately, through
[a security advisory](https://github.com/reiwand/reiwand/security/advisories/new), not in an issue.
Say what can be done, how, and with which version (`reiwand-ctl --version`).

These are security problems:

- A package, a scene script, a web wallpaper or a provider plugin that reaches files, hosts or
  devices it should not, or escapes its sandbox or its limits.
- A package or a repository accepted with a signature that does not match, or swapped without the
  fingerprint noticing.
- A key, a password or a private file that leaves the computer or the phone unasked, or is stored
  in the clear.
- Anything that lets someone else act on your own server or account.

Only the latest release is fixed. A fix is published with the release that carries it.
