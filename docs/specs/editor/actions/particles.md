changing the units converts the current value so the bend stays the same, using half the mean `size` of the system; the particles panel shows the selector "proportional to the size / in pixels" next to the slider, the selector of the color (only bend, multiply, add, add the bent picture as light) and the shift in pixels of each level); `cutout`, `orient`, `shader`, `strand`, `texture`, `lit` and `refract` take a `layer` to change the render of that particles layer, which starts as a copy of the render of the system.
