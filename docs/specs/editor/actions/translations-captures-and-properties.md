# Translations, captures and properties

| Action | Arguments | Command |
|--------|-----------|---------|
| `translate` | `pointer` to a text of the manifest or of the scene (the `placeholder` of a `media` text; the `text` of a text layer, unless it follows a value), `language`, `text` (an empty or missing one removes that language), `add` (adds a language the text lacks, starting from the text in the default language, and leaves one it has alone) | `translate DIR POINTER LANGUAGE TEXT`, `--remove` or `--add` |
| `thumbnail` | `file`, `animated`; copies a picture into `assets/` as `previews.thumbnail` or `previews.animated` | `thumbnail DIR FILE [--animated]` |
| `shot` | one of `still` (`time`, the second of the scene, `base`, the file of the base package of a preset, which is drawn with the values of the preset; its `poster_time` without it: draws the scene and keeps the frame as the thumbnail, at most 1024 pixels), `recording` (`from`, `seconds` 0.1 to 15, `fps` 1 to 30, `format` `gif` or `webp`, `gif` without it, and `base` as in `still`; records a gif or a lossless animated webp of at most 640 pixels and 8 MiB, made smaller until it fits, as the animated preview) or `flashes` (`from`, `seconds` and `fps`, 0, 8 and 15 without them; measures how much the scene flashes and keeps the result next to the editor state of the folder, for the scene as it is, so that later processes find it with the query `flashes`); scenes on the graphics card of the process; a picture package keeps its own picture (`still` only) and a video package a frame or a recording of the video; a web page is not drawn by the editor: `reiwand-ctl scene thumbnail DIR --capture [--output SCREEN]` shows it on a screen through `PreviewScene` and reads the frame back with `CapturePage` (`dbus.md`), so the helper, the sandbox and the network rules are exactly those of a shown page; a preset draws its base: a scene with the values, a picture or a video cropped by its `zoom`, `x`, `y` and started at `start`, a web page through the daemon with the values as `preview.values` (`flashes` is for scenes only) | `thumbnail DIR --capture [--time S]`, `thumbnail DIR --capture --animated [--from S] [--seconds N] [--fps F] [--format gif|webp]`, `scene ask DIR flashes '{"run": true}'` |
| `add_property` | `kind` (`slider`, `bool`, `color`, `combo`, `text`, `file`, `folder`, `shortcut`, `button`, `group`, `label` or `divider`), optional `id` (`<kind>_<n>` when omitted), `group`, `label`; the property starts valid, last of its group, and a combo with the options `option_1` and `option_2` and empty labels, so no text in a language the package may not use is written | `add-property DIR KIND` |
| `move_property` | `id`, `to` (its position among the properties of its group, 0 first), optional `group` (an empty one takes it out of its group); the `order` of that group becomes 1, 2… | `move-property DIR ID TO` |
| `rename_property` | `id`, `to`; the bindings, `prop:` triggers, groups, conditions (maps and expressions) and preset values that name it follow; scripts are not rewritten, and the command warns about each script that names the old id in quotes | `rename-property DIR ID TO` |
| `remove_property` | `id`; removes the property, its values in presets and in conditions that are maps, and the `group` of its members; refused, naming each place, while a binding, a `prop:` trigger or an expression condition names it; the command warns about scripts as `rename_property` does | `remove-property DIR ID` |
| `condition` | `id`, `text`, `enabled`: sets `visible_if`, or `enabled_if`, to the expression or, when `text` is a JSON object, to that map; refuses a condition that does not check, and an empty one removes it | `condition DIR ID TEXT [--enabled]` |
| `add_preset` | optional `id` (`preset_<n>` when omitted), `label`; a preset without values | `add-preset DIR` |
