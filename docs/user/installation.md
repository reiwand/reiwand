# Installation (without root)

Reiwand installs from an AppImage into your home directory, without root, and updates itself. Each
release can be checked against its signed `SHA256SUMS`. The pages below go from download to
updates.

- [Download and install the AppImage](installation/appimage.md): check a release, install,
  uninstall and run without installing.
- [Requirements](installation/requirements.md): what the system needs, and what comes with Reiwand.
- [Setting up Plasma and the tray](installation/plasma.md): the desktop and lock screen wallpaper,
  the tray icon, the filter and the app's pages.
- [Updates and versions](installation/updates-and-versions.md): automatic updates, data from
  another version, and how versions are numbered and published.
