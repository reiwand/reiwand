# Android

Reiwand runs on Android phones as the **reiwand** app, a live wallpaper with the same renderer,
library and rotation logic as the desktop. It shows photos, videos, scenes and web pages, with
lists, parallax and depth maps computed on the phone. These pages cover it in reading order.

- [Installing on Android](android/install.md): which APK to download and how to install it.
- [The app and the library](android/library.md): the three tabs, adding photos and videos, and selecting several.
- [Images and setting the wallpaper](android/images.md): fit, framing, home and lock screens, and supported formats.
- [Lists](android/lists.md): lists that change by themselves, their rules and smart searches.
- [Videos](android/videos.md): playback, conversion for the phone, HDR and video package settings.
- [Parallax and depth](android/parallax-depth.md): moving the image with the phone, depth maps and depth layers.
- [Packages](android/packages.md): examples, package types, presets, dependencies and mature content.
- [Scenes](android/scenes.md): the scene engine, properties, folders, scripts and quality levels.
- [Media, sound and touch](android/media-sound-touch.md): what plays, reacting to sound and touch, and scene sound.
- [Settings](android/settings.md): fit, frame rate, filter, system colors, diagnostics and licenses.
