# Your own server

`reiwand-server` publishes a signed repository of packages, a web catalog without JavaScript,
accounts with uploads and moderation, and device sign-in with a code. It is a single binary in a
container, everything lives in one data folder, and it sends no telemetry. These pages explain how
to run it and use it, in reading order.

- [Installing the server](server/install.md): with Docker or without it, the first administrator and the repository.
- [Image and configuration](server/configuration.md): the published image, checking it, building it, and the environment variables.
- [HTTPS](server/https.md): the server's own certificate on a home network, or a reverse proxy with a domain.
- [Backups and data from another version](server/backups-and-versions.md): backup, restore, and data made by another version.
- [Repositories and accounts](server/repositories-and-accounts.md): repository addresses, accounts, sign-in and the terminal commands.
- [Uploads and the catalog](server/uploads-and-catalog.md): hidden uploads, mature packages, the web catalog, featured packages and votes.
- [Taking a wallpaper away](server/taking-wallpapers-away.md): withdrawing, hiding and deleting packages and repositories.
- [Author keys and package tools](server/author-keys.md): online author keys, the editor's key and check tools, and *Edit a copy…*.
- [Static repositories](server/static-repositories.md): the *Static repository* tab of the desktop app and its terminal commands.
- [Moving the configuration to another computer](server/moving-configuration.md): export and import of a computer's configuration.
- [Scene properties](server/scenes.md): how scenes are drawn, their properties in the terminal and the app, and benchmarks.
- [Example scenes and sound](server/scene-sound-and-examples.md): the bundled example scenes and how scene sound works.
