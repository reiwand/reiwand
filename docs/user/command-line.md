# Using it from the terminal

`reiwand-ctl` controls Reiwand from the terminal: it sets wallpapers, changes settings, manages the
library, providers and repositories, and edits images. `reiwand-ctl <group> --help` shows each
command. The pages below go from everyday use to the details of rendering and editing.

- [Everyday commands](command-line/everyday-commands.md): setting wallpapers, fit modes, settings and the configuration file.
- [Stepping through wallpapers with the keyboard](command-line/stepping-with-the-keyboard.md): previewing the next or previous wallpaper and global shortcuts.
- [Library, lists and packages](command-line/library-lists-and-packages.md): commands for the library, lists, profiles, packages and scene input, and how the library behaves.
- [Scripts, jobs and output](command-line/scripts-jobs-and-output.md): output, jobs, secrets, exit codes, language and commands without a daemon.
- [Providers](command-line/providers.md): the Wallhaven provider and provider plugins.
- [Repositories](command-line/repositories.md): failures, provider downloads, animated previews and a home-network repository.
- [Accounts and the phone's repositories](command-line/accounts-and-phone.md): accounts, moving the configuration, and the phone's sources and updates.
- [Frame rate and automatic scene quality](command-line/frame-rate-and-automatic-quality.md): the frame rate cap and how scenes choose their quality level.
- [Choosing the scene quality](command-line/choosing-scene-quality.md): fixed levels and minimums, cost warnings and limits.
- [HDR, power, motion and flashing](command-line/hdr-power-and-motion.md): HDR screens, battery and heat, reduced motion, software rendering and flashing wallpapers.
- [Choosing the graphics card](command-line/graphics-card.md): the default card, `render.gpu` and how cards are identified.
- [Streams and video decoding](command-line/streams-and-video-decoding.md): zero-copy streams and video, and measurements on NVIDIA.
- [Editing images](command-line/editing-images.md): the image editor, `reiwand-ctl edit` and spanning screens.
- [Depth maps and parallax](command-line/depth-and-parallax.md): parallax movement, depth maps and the depth model.
- [3D parallax layers](command-line/parallax-layers.md): how layers are built and filled, and the author tools.
