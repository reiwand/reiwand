# User properties and presets in the editor

A user property is a setting that you declare and that whoever uses the wallpaper can change: a speed slider, a color, a switch, a list of options. A preset is a set of values for those properties that is applied with one click. These pages explain how to create them, order them, link them to layers, give them conditions, translate them and test them.

How each property is written inside the files is in [properties](properties.md). The package's own data (title, license, credits, network, permissions...) is in [package](package.md); here only what touches properties, presets and translated texts is covered. The terminal operations are called actions and are listed in [actions](actions.md). The rest of the editor is in [editor](editor.md).

User properties in the editor, by task:

- [Adding properties](editor-properties/adding.md): where everything is, the types, labels, help, icons and sliders.
- [Other types and order](editor-properties/types-and-order.md): the other types, order, groups, renaming and removing.
- [Following properties and conditions](editor-properties/behavior.md): layers that follow a property, conditions, buttons and quality levels.
- [Translations and presets](editor-properties/presets.md): translations, package presets, testing as the user and video presets.
- [Making a preset package](editor-properties/preset-packages.md): a package that is a preset of another.
