# The scene editor: getting started, saving, undo, preview and shortcuts

This is the entry page of the app's scene editor. It explains how to open or create a scene, what the window looks like, how to save and recover, how to undo, what the problems list says, how to see the scene at each quality level and what it costs, how to create the package, and which keys there are.

The other editor pages cover each area in depth: [canvas](editor-canvas.md), [animation](editor-animation.md), [drawing](editor-drawing.md), [effects](editor-effects.md), [particles and sound](editor-particles-and-sound.md), [3D](editor-3d.md) and [properties](editor-properties.md). Every editor change is an action that can also be run from the terminal; the full list is in [actions](actions.md) and the rest of the commands in [cli](cli.md).

The editor, by task:

- [The editor and its window](editor/opening.md): what the editor touches, the window and opening a scene folder.
- [Creating, saving and undoing](editor/creating-and-saving.md): creating a scene, editing a copy, saving, recovering and undoing.
- [Problems and previews](editor/checking-and-viewing.md): the problems list, the preview, the desktop and quality levels.
- [Cost, the package and the image editor](editor/cost-and-package.md): costs, making and applying the package and the image editor.
- [All keyboard shortcuts](editor/shortcuts.md): every key of the editor.
