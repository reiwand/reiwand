# All keyboard shortcuts

With “Standard” the combination your system gives to that action is used, normally **Ctrl+Z** to undo, **Ctrl+Shift+Z** or **Ctrl+Y** to redo, **Ctrl+S** to save, **Ctrl+C**, **Ctrl+V** and **Delete**.

| Shortcut | What it does | Where it works |
|---|---|---|
| Undo (standard) | Undoes the last step | Scene editor window; package window ([package](../package.md)); image editor |
| Redo (standard) | Redoes the undone step | The same three places |
| Save (standard) | Saves the scene (only if there are changes) | Scene editor window; package window |
| Save (standard) | Saves the script or the effect code you are writing | **Code** panel (**Save**) |
| Ctrl+Tab, Ctrl+Shift+Tab | Next or previous file open in Code | **Code** panel, when it has the keyboard |
| **F6**, **Shift+F6** | Takes the keyboard to the next or previous group of panels (a side folded into a rail is one stop) | Scene editor and package windows |
| **Ctrl+Tab**, **Ctrl+Shift+Tab** | Next or previous tab of the group that has the keyboard | The workbench (in **Code** it changes the open file) |
| **F11** | Makes the panel that has the keyboard fill the window, or returns it | The workbench |
| **Escape** | Folds again a panel opened from a rail | The workbench, with a narrow window |
| **Ctrl+1** to **Ctrl+6** | Chooses the layout **Scene**, **Particles**, **Scripts**, **Simulation**, **Animation** or **Wallpaper** | Scene editor and package windows |
| **Ctrl+7** to **Ctrl+9** | Chooses your first three saved layouts | Scene editor and package windows |
| **Alt**, **Alt** and a letter | Goes to the menus (**Alt** alone to **File**); **Alt+F**, **Alt+E**, **Alt+L**, **Alt+V**, **Alt+W** open one | The top bar |
| Menu key or **Shift+F10** | Opens the menu of the chosen tab: move it, stack it, detach it, maximize or close it | A panel's tab, the canvas's included |
| **Tab**, then arrows | Moves the chosen edge between two groups; **Enter** puts it back | The edges between groups |
| **Space** | Plays or pauses | **Timeline**, when it has the keyboard |
| **Home**, **End** | Goes to the start or the end | **Timeline** |
| **Left**, **Right** | Moves the playhead 0.1 s (1 s with **Shift**) | **Timeline** |
| Arrows | Moves the chosen layer 1 pixel | The scene editor canvas, when it has focus |
| **Shift** and arrows | Moves the chosen layer 10 pixels | The scene editor canvas |
| **Escape** | Cancels **Follow a layer** while you wait to touch the layer | The scene editor canvas |
| **Escape** | Closes the level panel | **Preview level** |
| Copy (standard) | Copies the chosen keys | **Curve editor** (with keys chosen) |
| Paste (standard) | Pastes the copied keys | **Curve editor** |
| **Delete** | Removes the chosen keys | **Curve editor** (with keys chosen) |
| **F** | Frames the chosen keys | **Curve editor** (with keys chosen) |
| **Home** | Frames all the keys | **Curve editor** |
| **\\** (backslash) | Turns **Compare with the original** on or off | Image editor |

The canvas takes keyboard focus when you choose a layer in the list, when you touch or drag a layer and when you touch the empty canvas; that is why the arrows work right away. Each arrow press is an undo step.

The keys that change how the mouse works:

| Combination | What it does | Where |
|---|---|---|
| **Ctrl** and wheel | Zooms the canvas in or out | Canvas |
| Wheel | Scrolls the view | Canvas |
| Middle or right button and drag | Moves the view | Canvas |
| **Ctrl** and click | Adds the layer to the chosen ones (to group, copy or remove) | Layer list and canvas |
| Right click, menu key or **Shift+F10** | Opens the menu for what is chosen | Layers, canvas, timeline and **Assets** |
| **Alt** and drag | Places the layer without it snapping to the magnets | Canvas |
| **Shift** and drag a corner | Scales keeping the proportions | A layer's handles |
| **Ctrl** and drag the middle of an edge | Skews the layer along that edge | A layer's handles |
| **Shift** and drag an end | Moves the whole line | Handles of an effect with two points |
| **Shift** and drag a corner of a shape | Resizes keeping the proportions | A shape's handles |
| **Ctrl** and click on a key | Adds the key to the chosen ones | **Curve editor** |
| **Alt** and drag a key | Scales the values of the chosen keys | **Curve editor** |
| **Shift** and wheel | Scrolls the time axis | **Curve editor** |
| **Ctrl** when starting to drag a clip key | Copies it instead of moving it | A clip's strip ([animation](../editor-animation.md)) |
| **Ctrl** and drag a handle | Moves along the line of sight | 3D handles of cameras, lights and models ([3D](../editor-3d.md)) |
| **Shift** and drag a model handle | Replaces a linked value with a fixed value | A 3D model's handles |
| Right button and drag | Rotates the view | 3D view |
| Middle button or **Shift** and drag | Slides the view | 3D view |
| Wheel | Zooms in | 3D view |
